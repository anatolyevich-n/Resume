# 📊 [Изучение данных по продажам автомобилей]

> Произведен разведочный анализ учебного датасета. Выявлены пропуски, изучены самые частые категории и выявлен тип распределения данных по пробегу авто.  .

---

## 🎯 Цель проекта

Освоить EDA. Научиться интерпретировать данные и находить экстремальные значения и пропуски в данных. Научиться принимать решение по обработке пропусков. Научиться формулировать гипотезы и делать выводы на основе визуализаций при помощи встроенных библиотек Python

---

## 🗺 Структура проекта
- импорт учебного датасета с помощью библиотеки pandas
- информация о размере датасета и типе данных с помощью команды car.info()
- подсчет статистик для числовых столбцов car.describe().round(2)
- построение матрицы пропусков
- подтверждение гипотез на основе визуализации данных: как распределен пробег? какой цвет авто встречается чаще? Какой тип трансмиссии наиболее распространен ?
