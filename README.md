# 2. Проверка гипотез
> Проверка гипотез на двух тестовых выборках роста мужчин и женщин с помощью t-Тест Стьдента. Визуализация различий, принятие решения о статистической значимости



## 🎯 Цель проекта

Научиться формулировать гипотезы. Научиться использовать t-тест для их проверки. Закрепление навыков визуализации. 

## 🗺 Итог
В результате проверки двух выборок были сделаны выводы: график подтверждает, что разница есть: мужчины в среднем выше женщин. Но с точки зрения реальных задач эта разница не существенна и ее можно но учитывать.

Статистическая значимость ≠ практическая важность.

На большой выборке почти любая разница будет статистически значимой. Поэтому p‑значение само по себе не говорит, насколько эффект важен в реальности.

Когда n (кол - во значений выборки) очень велико - стандартная ошибка среднего становится крошечной, и даже минимальная разница в средних значениях дает огромное значение t - теста, что в свою очередь приводит к уменьшению p-value, поэтому тест становится гиперчувствительным
